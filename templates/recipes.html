Overview

Application web développée avec Django durant mon stage chez Visual Vibes. Mise en place d’un système complet de gestion collaborative de recettes avec authentification sécurisée, interactions utilisateurs et architecture MVT structurée.

Réalisations

  • Architecture Django MVT complète
  • Système d’authentification sécurisé
  • Modélisation relationnelle avancée
  • CRUD avec permissions par auteur
  • Système de notation avec moyenne dynamique
  • Workflow Git professionnel
